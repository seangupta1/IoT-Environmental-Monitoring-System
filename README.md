# IoT Environmental Monitoring System

A web-based IoT system for monitoring environmental conditions using an ESP32 with temperature and humidity sensors. Sensor readings are sent to a Flask web application, stored in a database, and displayed through a web dashboard.

## Features

* ESP32-based temperature and humidity monitoring
* Sends sensor readings to the server over HTTP
* Flask web application
* User registration and authentication
* Database storage of sensor readings
* Real-time temperature and humidity monitoring
* Historical temperature data visualization
* Sensor connection and status monitoring
* Integration with an external weather API

## Technologies

* **Hardware:** ESP32, temperature/humidity sensor
* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite
* **Data Validation:** Pydantic
* **Communication:** HTTP
* **APIs:** Flask API, Weather API
